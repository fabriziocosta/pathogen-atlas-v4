# Pathogen Atlas V4 Explorer

The Explorer is the interactive view of the Pathogen Atlas. It lets users search pathogens, filter evidence by host, review linked PubMed records and their titles, and inspect pathogen features in the context of a host relationship.

Open the [Pathogen Atlas Explorer](index.html). It is published through GitHub Pages. Its payload combines validated V4 host and taxonomy records with provenance-marked historical human profiles and literature titles.

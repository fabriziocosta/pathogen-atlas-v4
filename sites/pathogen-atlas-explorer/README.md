# Pathogen Atlas V4 Explorer

The Explorer is the interactive view of the Pathogen Atlas. It lets users search pathogens, filter evidence by host, review linked literature and supporting passages, and inspect pathogen features in the context of a host relationship.

Open the [Pathogen Atlas Explorer](index.html). The static application is published through GitHub Pages, with its data payload built from validated Atlas records by `scripts/build_v4_site_data.py`.
